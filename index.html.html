Problem Statement

Tomato is highly perishable. Transport distance, storage temperature, storage duration, and vibration level can significantly reduce product quality and cause economic losses.

Project Objectives

Predict quality loss

Estimate deterioration under transport and storage conditions.

Classify market status

Assign Marketable, Fast sale required, or Unmarketable labels.

Support decisions

Provide a practical tool for logistics, storage, and sales planning.

Input Parameters

Transport distance

Distance traveled in kilometers.

Storage temperature

Storage condition in degrees Celsius.

Storage day

Number of days after transport.

Vibration level

Relative vibration intensity during transport.

Output Classes

Marketable

Suitable for normal sale conditions.

Fast sale required

Still saleable, but should be sold quickly.

Unmarketable

Predicted to be unsuitable for market sale.

Key Findings

  • Regression model predicts quality losses close to real values.
  • Classification model assigns practical marketability classes.
  • Storage duration was the strongest factor in the current prototype dataset.
  • Example severe scenario: 205 km, 22°C, 12 days, vibration 1.3 → Unmarketable.
